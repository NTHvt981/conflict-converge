# Structure based on current folder

```Folder structure
├─ project-planning -> put all planning files here
│   └─ MILESTONE.md -> we devide development process into multiple milestones,
│                      each with clear goals, implementation steps
└─ conflict-converge -> where we implement actual project
    ├─ deps -> where we put git dependencies
    │   ├─ raylib
    │   ...
    ├─ tests -> put test files here
    │   └─ unit-tests
    ├─ prj -> where we put project files generated by premake (.prj, .sln)
    │   ├─ conflict-converge.sln
    │   ├─ test.prj -> correspond with folder tests/
    │   └─ game.prj -> correspond with folder src/game/
    ├─ src -> where we put game source code in (.inl, .h, .cpp)
    │   └─ game
    │       ├─ main.cpp -> entry point of game
    │       ├─ private -> put .cpp files here
    │       │   ├─ Game.cpp
    │       │   ...
    │       └─ public -> put .h files here
    │           ├─ Game.h
    │           ...
    ├─ .gitignore
    ├─ bootstrap.py
    ├─ lib_deps.json
    ├─ premake5.exe
    ├─ premake5.lua
    └─ README.md
```
